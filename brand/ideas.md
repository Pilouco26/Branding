# Idees de marca (origen)

Documentació de les idees aportades per l’equip — no del sistema executat. Serveix com a memòria de direcció creativa.

## Context

- Construir **logo, colors i màrqueting** en aquest directori (`MARCA`).
- Referència de mètode: [Venngage — logo design tips](https://venngage.com/blog/logo-design-tips/).
- Generació de logo amb el skill `svg-design` de `git@github.com:tryopendata/skills.git`.

## Qui és Piricodi

- **Fàbrica de software andorrana.**
- Imatge a transmetre: **sofisticació** i **modern / nou**.
- Orgull de dos eixos:
  1. Els **Pirineus**
  2. El **software ben fet**

## Posicionament (respostes de briefing)

| Pregunta | Idea |
|----------|------|
| Públic | Empreses **locals** |
| Promesa | **Partner d’enginyeria fiable** (*reliable engineering partner*) |
| Nom | **Piricodi** com a base, més **alternatives curtes** a explorar en paral·lel |
| Visual | **Subtil** (Pirineus) + **sharp tech** |
| Idioma | **Català** primer |
| Superfícies | **Web**, **factures**, **pitch decks** |

## Direcció visual (iteracions)

### Inicial

- Sofisticat, modern, no folklòric.
- Pirineus de forma **subtil**, no literal (evitar caricatura / bandera).
- Tech nítid, geomètric, autoritari però net.

### Ajust posterior

- Logos **més 3D** (volum, facetes, profunditat).
- Colors **més suaus**.
- Direcció de color: **verd emerald**.

### Decisió de color

- Entre tres propostes (Estany, Pissarra, Prat i granit), es tria **A · Estany**: emerald fresc i boira d'alta muntanya.

## Idees de nom a explorar

A més de **Piricodi** (Pirineus + codi), es van demanar alternatives curtes per comparar. Al set de logos van entrar, entre d’altres:

- **Piri** — forma curta
- **Cimal** — cim / ambició (català)
- **Cresta** — cresta de muntanya
- **Forja** — fàbrica / artesania

## Què ha de “fer” el logo

- Explicar qui som i d’on ve el caràcter (Andorra / Pirineus + enginyeria).
- Funcionar **gran i petit** (favicon → hero / deck).
- Ser usable en capçalera de **factura** (sobri) i en **pitch** (més expressiu).
- Transmetre confiança de partner, no hype de startup.

## Fora d’abast (aquesta fase)

- Web completa
- Registre de marca / legal
- Assets d’impressió més enllà de vectors SVG
